# Projektnotizen für Claude

## Pull Requests

Wenn im Rahmen einer Aufgabe ein Pull Request erstellt wird, darf er nach dem
Erstellen automatisch selbst gemerged werden, ohne vorher extra nachzufragen
(sofern keine offensichtlichen Probleme wie fehlschlagende Checks oder
Konflikte vorliegen). Der Nutzer möchte hier nicht jedes Mal manuell
bestätigen müssen.
